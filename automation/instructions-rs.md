# Instructions for the Roos–Seeger (RS) formalization

These are the standing instructions for the task of formalizing **Theorem 1.1 of
[arXiv:2004.00984](https://arxiv.org/abs/2004.00984)** (Joris Roos, Andreas Seeger,
*Spherical maximal functions and fractal dimensions of dilation sets*, Amer. J. Math. **145** (2023),
1077–1110). Future agents working on this task must follow them.

## Goal

Formalize, `sorry`-free and depending only on the standard axioms
(`propext`, `Classical.choice`, `Quot.sound`):

> **Theorem 1.1.** Let `d ≥ 2` and `E ⊆ [1,2]`, `β = dim_M E`, `γ = dim_qA E`.
> Then `R(β,γ) ⊆ T_E`.

Here `dim_M` is the upper Minkowski dimension, `dim_qA` the quasi-Assouad dimension,
`Q(β,γ)` the closed convex hull of `Q₁, Q₂,β, Q₃,β, Q₄,γ`, and `R(β,γ)` is
`interior Q(β,γ)` together with the half-open segment `[Q₁, Q₂,β)`.

The statement must be **true to the mathematical statement in the paper**. In this repository the
AHRS formalization already proves exactly this inclusion under the extra hypothesis
`3 ≤ d ∨ (d = 2 ∧ γ ≤ 1/2)`. The new mathematical content is therefore the case

> **d = 2, γ > 1/2**

which is the content of the paper's Theorem 2.5 (`thm:Q4`) plus the interpolation in
Corollary 2.6 (`cor:interior`).

## After Theorem 1.1: Theorem 1.2

Once Theorem 1.1 is completely formalized (`sorry`-free, standard axioms only), **continue with
Theorem 1.2 of the same paper** ([arXiv:2004.00984](https://arxiv.org/abs/2004.00984)), under the
same rules as below (same file layout, same `Auto` namespace, same strict-forward-reasoning
method, same reporting discipline in `Report.md`).

**Do not guess the statement.** The precise statement of Theorem 1.2 has not been read off the
source in the session that added this note, so the first step of that phase is to obtain the
paper's Theorem 1.2 verbatim and record it at the top of the new work, exactly as the Theorem 1.1
statement is recorded above. Only then begin formalizing.

### The statement, verbatim from the source (`circular.tex`, `egin{thm}\label{thm:type}`)

> **Theorem 1.2.** Let `W ⊆ [0,1]²`. Then
>
> (i) `W = closure(T_E)` holds for some `E ⊆ [1,2]` if and only if `W` is a closed convex set and
> `Q(β,γ) ⊆ W ⊆ Q(β,β)` for some `0 ≤ β ≤ γ ≤ 1`.
>
> (ii) For `W = closure(T_E)` in the display above one necessarily has `dim_M E = β` and if in
> addition `γ` is chosen minimally, then `dim_qA E = γ`.

Remark 1.4 of the paper (for every `γ_* ∈ [γ,1]` the set `E` can be chosen with
`dim_A E = γ_*`) is a *remark*, not part of Theorem 1.2, and was not formalized.

**Status: complete (2026-08-28).** Both parts are in `LeanSpherical/Theorems.lean` as
`Spherical.FractalDilations.closure_fractalTypeSet_iff_isClosed_convex_sandwich` and
`Spherical.FractalDilations.dimensions_of_sandwich_closure_fractalTypeSet`, sorry-free, axioms
`[propext, Classical.choice, Quot.sound]`. See Milestone 20 in `Report.md`.

## Method

* Reuse what the repository already has. In particular the AHRS development in
  `LeanSpherical/Auto/Spherical/FractalDilations/` (see `ProofSkeleton.lean`,
  `Theorems.lean`), `Auto/SteinInterpolation.lean`, `Auto/Spherical/SurfaceCore.lean`,
  `Auto/Spherical/InterpolationCore.lean`, and the MSS/Bourgain files.
* **Strict forward reasoning.** Follow the logical path of the paper linearly. Do not start a step
  before the previous one is faithfully complete. Do not dodge a hard step by introducing a
  wrapper, a weakened statement, or an extra hypothesis.
* Repository conventions: header comment `/- This file was machine-generated by ... -/`, plain
  `import` lines, a `/-! ... -/` module docstring, then `namespace Auto.<Path>`.
* Do not ask the user questions. Make judgment calls and record them in `Report.md`.
* `Report.md` is an executive summary: record judgment calls, and record each milestone **only once
  it is completely finished**. Keep it short.
* **Reporting discipline for milestones (mandatory, set by the user on 2026-08-27).**
  * A `Report.md` entry counts as a **milestone only if it completely proves a significant
    step or part of the paper** — a numbered theorem, proposition, corollary, or a self-contained
    section of the logical path.  Infrastructure, instantiations, API, refactors and partial steps
    are *not* milestones: record them under a `Progress` heading instead.
  * **Every milestone entry must carry a timestamp** (local date and time, e.g.

## Proof skeleton of the new case (paper §2–§4)

Notation: `A_t f = f * σ_t`; `A^j_t` is the `j`-th dyadic frequency piece;
`χ^E_{A,γ}(δ) = sup_{|I| ≥ δ} (δ/|I|)^γ N(E ∩ I, δ)` is the γ-Assouad characteristic;
for `d = 2`, `Q₄,γ = (1/p₄, 1/q₄)` with `q₄ = 3 + 2γ`, `p₄ = (3+2γ)/2`.

1. **Theorem 2.5 (`thm:Q4`).** `d = 2`, `γ ≥ 1/2`, `j ≥ 0`:
   `‖sup_{t∈E}|A^j_t f|‖_{q₄} ≤ c · min(j^{1/2}/(2γ−1), j)^{1/p₄} · [χ^E_{A,γ}(2^{-j})]^{1/q₄} ‖f‖_{p₄}`.
2. **§3 (fractional integration).** Reduce to a bilinear operator `T_j` acting on
   `L^{p₄}(ℝ²) × L^{p₄}(ℝ²) → L^{p₄}(ℝ² × E)`, via: dyadic `t`-discretization + fundamental theorem
   of calculus, bilinearization, then analytic interpolation of the weighted `L²` bound
   (Proposition 3.2) against a trivial `L¹ → L^∞` bound, followed by one-dimensional fractional
   integration (Hardy–Littlewood–Sobolev on `ℝ`).
3. **Proposition 3.2 (`prop:l2`), the heart.** With `w_γ(y,z) = |y−z|^{-(2γ−1)}` and `E`
   uniformly `2^{-j}`-separated:
   `‖T_j F‖_{L²(ℝ²×E)} ≤ c min(j^{1/2}/(2γ−1), j) 2^j [χ^E_{A,γ}]^{1/2} ‖F‖_{L²(w_γ)}`.
4. **§4.** Second dyadic decomposition in the angle `∠(ξ,η)` (`m`-decomposition), then three
   estimates for `S[F,b]`:
   * Prop. 4.2 (trivial): Cauchy–Schwarz in `η`.
   * Prop. 4.3 (almost orthogonality): polar coordinates, two integrations by parts in `ρ` against
     the phase `τ(ρ) = |ξ−ρθ| + ρ` with `τ' ≈ 2^{-2m}`, plus the uniform separation of `E`.
   * Prop. 4.4 (off-diagonal decay): integration by parts in `η`, then **Calderón–Vaillancourt**
     for the exotic symbol `a_{t,ξ}(w,η) = L_{t,ξ,w}[b(t,ξ,·)](η) ψ(2^{m−ℓ}w)` (§4.3).
5. **Corollary 2.6 + Theorem 1.1.** Interpolate `thm:Q4` with the `L²` bound
   `(2.9)`/`(2.10)` and the `Q₁,Q₂,Q₃` bounds already in the repository, then sum over `j`
   using `χ^E_{A,γ}(δ) ≤ 2δ^{-ε} + C(ε,ε₁)δ^{-ε₁}` (which is where `dim_qA E = γ` enters).
